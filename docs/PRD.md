# PRD: 나의 Todo 앱

## 1. 배경과 목표
할 일을 적고, 마감일과 카테고리로 정리하고, 달력으로 한눈에 확인하는 **가볍고 설치 부담 없는 할 일 관리 앱**.
Python만으로 만들고, 파일 하나(SQLite)에 저장해서 내려받은 그대로 실행되는 것을 목표로 한다.

## 2. 대상 사용자
- 혼자 쓸 할 일 목록이 필요한 개인 사용자
- 복잡한 계정 가입이나 서비스 설치 없이 바로 쓰고 싶은 사람

## 3. 기능 요구사항

### 필수 (CRUD)
| 기능 | 설명 |
|---|---|
| 추가 | 제목(필수), 마감일(선택), 카테고리를 입력해 할 일을 만든다. |
| 조회 | 목록에서 미완료 → 완료 순, 마감일 순으로 본다. |
| 완료 | 체크박스로 완료/미완료를 바꾼다. |
| 삭제 | 삭제 버튼을 누르고 한 번 더 확인한 뒤 지운다. |

### 추가 기능
| 기능 | 설명 |
|---|---|
| 마감일 표시 | 오늘 마감은 노란색, 기한이 지난 일은 빨간색으로 표시한다. 날짜는 한국 시간 기준이다. |
| 카테고리 | 카테고리마다 고정된 색을 붙이고, 카테고리별로 골라 볼 수 있다. |
| 캘린더 보기 | 월간 달력에 마감일별로 할 일을 보여 준다. 한 칸에 3개까지 보이고 나머지는 "+N개 더"로 표시한다. |
| 구글 캘린더 내보내기 | `.ics` 파일을 받아 구글 캘린더에서 가져온다. |

## 4. 범위 밖 (이번 버전에서 하지 않는 것)
- 로그인과 사용자별 데이터 분리
- 알림, 반복 일정, 다른 사람과 공유
- 모바일 앱

## 5. 데이터 구조 (`todos` 테이블)
| 열 | 종류 | 설명 |
|---|---|---|
| id | INTEGER (자동 증가) | 고유 번호 |
| title | TEXT (필수) | 할 일 내용 |
| done | INTEGER (0/1) | 완료 여부 |
| due_date | TEXT (선택) | 마감일 (YYYY-MM-DD) |
| category | TEXT (기본값 '일반') | 카테고리 |

## 6. 기술 구성
Python, Streamlit(화면), SQLite(저장), python-dotenv(설정). 모두 무료. 설정은 `.env`에서 읽고 없으면 기본값(`todo.db`)을 쓴다.

## 7. 비기능 요구사항 (보안과 품질)
- 사용자 입력은 HTML로 출력하기 전에 이스케이프한다.
- DB 쿼리는 자리표시자(`?`)로 값을 전달한다.
- 비밀값은 코드에 쓰지 않고 `.env`에만 두며, `.env`와 `todo.db`는 저장소에 올리지 않는다.
- 패키지 버전은 `requirements.txt`에 고정한다.

## 8. 성공 기준
- 내려받아 명령 두 줄(설치, 실행)로 바로 실행된다.
- 할 일 추가부터 완료 처리까지 한 화면에서 끝난다.
- 앱을 껐다 켜도 데이터가 남는다. (로컬 실행 기준)

## 9. 알려진 한계와 다음 계획
| 한계 | 설명 | 다음 계획 |
|---|---|---|
| 데이터 공개 | 배포 서버(streamlit.app)는 로그인 없이 DB 하나를 모두가 함께 쓴다. | 앱을 비공개로 제한하거나, 로그인과 사용자별 분리를 추가한다. |
| 데이터 초기화 | 무료 서버가 재시작되면 데이터가 사라질 수 있다. | 외부 DB를 사용한다. |
| 개인용 | 한 사람이 쓰는 것을 전제로 한다. | 사용자 계정을 도입한다. |
